# map/
> L2 | 父级: ../../CLAUDE.md

地图功能组件把静态节点投影为可操作详情；节点详情可展示垂钓环境摘要，但不承载会话状态或服务端权限判定。

成员清单

index.ts: 地图组件与节点详情类型的统一导出。
MapNode.tsx: 主地图节点标记。
MapSatellite.tsx: 卫星水域与历练节点标记。
MapNodeDetail.tsx: 节点详情、环境摘要与玩法入口。
MapSectLandmark.tsx: 宗门地标标记。
SectLandmarkDetail.tsx: 宗门地标详情与入口。
