# fishing/
> L2 | 父级: ../../../CLAUDE.md

垂钓共享领域规则，维护鱼种、水域、环境、经验、品质、鱼贸经济和灵池权重。规则保持纯函数，服务端负责持久化、锁和资源事件。

成员清单

catalog.ts: 鱼种与水域静态目录。
environment.ts: 鱼饵、鱼潮、天气、时辰、月相与异象目录。
types.ts: 鱼种、会话、成长与图鉴共享契约。
rules.ts: 水域解锁、鱼种抽取、品质、提竿窗口与经验规则。
economy.ts: 鱼货积分、相邻品阶升阶、灵池驯养阶段与目标鱼抽取。
rewards.ts: 每日次数与鱼种/品阶一次性奖励。
index.ts: 垂钓领域唯一公共导出入口。
rules.test.ts: 垂钓纯规则回归测试。
